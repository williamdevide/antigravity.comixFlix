# ComixFlix — Design System e UI/UX Completo

## Contexto
Você é um designer de produto sênior especializado em mobile-first e design systems. Estou criando o **ComixFlix** — a "Netflix dos quadrinhos físicos".

O objetivo é criar um design system completo, moderno e consistente, inspirado na Netflix, Comixology e Letterboxd, que seja escalável e fácil de implementar.

---

## Inspiração Visual

### Referências Principais
- **Netflix** (principal):
  - Carrosséis horizontais imersivos
  - Hero sections com overlays gradientes
  - Dark mode padrão
  - Tipografia bold e hierarquia clara
  - Microinterações fluidas (hover, tap, loading)
  
- **Comixology**:
  - Grid de capas (aspect ratio 2:3)
  - Fichas técnicas detalhadas
  - Sistema de séries e edições
  
- **Letterboxd**:
  - Sistema de status (quero/tenho/li)
  - Notas pessoais (1-5 estrelas)
  - Listas customizadas
  - Perfil social

### Princípios de Design
1. **Mobile-First**: Todas as decisões começam no mobile (320px+)
2. **Conteúdo é Rei**: Capas de quadrinhos são o protagonista
3. **Velocidade Percebida**: Skeleton screens, lazy loading, animações sutis
4. **Acessibilidade**: WCAG 2.1 AA (contraste, foco, labels)
5. **Consistência**: Padrões previsíveis em todas as telas

## Componentes Principais

### 1. Card de Quadrinho (Mobile)

#### Estrutura
```tsx
<ComicCard
  comic={{
    id: '123',
    titulo: 'Batman #1',
    url_capa: '/images/batman-1.jpg',
    preco_normal: 29.90,
    preco_promocional: 24.90,
    personagem_principal: 'Batman'
  }}
  userStatus="quero" // opcional: 'quero' | 'tenho' | 'li'
/>
```

#### Visual
- **Aspect Ratio**: 2:3 (capa de HQ)
- **Tamanho**:
  - Mobile: 140px largura (2 colunas com gap)
  - Desktop: 200px largura (5-6 colunas)
- **Estados**:
  - **Default**: Capa + título + preço
  - **Hover/Tap**: Overlay escuro + 4 ícones de ação
  - **Status ativo**: Badge no canto superior esquerdo

#### Anatomia do Card
┌─────────────────────┐
│ [Badge: Quero] │ ← Canto superior esquerdo (se status)
│ │
│ │
│ [CAPA 2:3] │ ← Imagem em full-bleed
│ │
│ │
│ ┌─────────────────┐ │
│ │ Batman #1 │ │ ← Título (2 linhas max, line-clamp)
│ │ R$ 24,90 │ │ ← Preço (verde se promoção)
│ └─────────────────┘ │
│ │
│ [❤️] [📚] [📖] [+] │ ← Ícones de ação (overlay, hover)
└─────────────────────┘


#### Código (Tailwind + Framer Motion)
```tsx
'use client';

import { useState } from 'react';
import { motion, AnimatePresence } from 'framer-motion';
import { Heart, Library, BookOpen, Plus } from 'lucide-react';

interface ComicCardProps {
  comic: {
    id: string;
    titulo: string;
    url_capa: string;
    preco_normal: number;
    preco_promocional: number | null;
    personagem_principal: string;
  };
  userStatus?: 'quero' | 'tenho' | 'li';
  onAction?: (action: 'quero' | 'tenho' | 'li') => void;
}

export function ComicCard({ comic, userStatus, onAction }: ComicCardProps) {
  const [showActions, setShowActions] = useState(false);
  const [status, setStatus] = useState(userStatus);

  const handleAction = (action: 'quero' | 'tenho' | 'li') => {
    setStatus(action);
    onAction?.(action);
  };

  return (
    <motion.div
      className="relative w-[140px] aspect-[2/3] rounded-md overflow-hidden cursor-pointer"
      onMouseEnter={() => setShowActions(true)}
      onMouseLeave={() => setShowActions(false)}
      onTap={() => setShowActions(!showActions)}
      whileHover={{ scale: 1.05 }}
      transition={{ duration: 0.2, ease: 'easeOut' }}
    >
      {/* Capa */}
      <img
        src={comic.url_capa}
        alt={comic.titulo}
        className="w-full h-full object-cover"
        loading="lazy"
      />
      
      {/* Overlay */}
      <div className="absolute inset-0 bg-gradient-to-t from-black/90 via-black/30 to-transparent">
        {/* Badge de Status */}
        <AnimatePresence>
          {status && (
            <motion.div
              initial={{ opacity: 0, scale: 0.8 }}
              animate={{ opacity: 1, scale: 1 }}
              exit={{ opacity: 0, scale: 0.8 }}
              className={`absolute top-2 left-2 px-2 py-1 rounded-sm text-xs font-semibold ${
                status === 'quero' ? 'bg-red-500 text-white' :
                status === 'tenho' ? 'bg-blue-500 text-white' :
                'bg-green-500 text-white'
              }`}
            >
              {status === 'quero' && '❤️ Quero'}
              {status === 'tenho' && '📚 Tenho'}
              {status === 'li' && '📖 Li'}
            </motion.div>
          )}
        </AnimatePresence>
        
        {/* Título e Preço */}
        <div className="absolute bottom-0 left-0 right-0 p-3">
          <h3 className="text-white text-sm font-bold line-clamp-2 leading-tight">
            {comic.titulo}
          </h3>
          
          <div className="mt-1 flex items-center gap-2">
            {comic.preco_promocional ? (
              <>
                <span className="text-green-400 font-bold text-sm">
                  R$ {comic.preco_promocional.toFixed(2)}
                </span>
                <span className="text-gray-400 text-xs line-through">
                  R$ {comic.preco_normal.toFixed(2)}
                </span>
              </>
            ) : (
              <span className="text-white text-sm">
                R$ {comic.preco_normal.toFixed(2)}
              </span>
            )}
          </div>
        </div>
        
        {/* Ícones de Ação */}
        <AnimatePresence>
          {showActions && (
            <motion.div
              initial={{ opacity: 0, y: 12 }}
              animate={{ opacity: 1, y: 0 }}
              exit={{ opacity: 0, y: 12 }}
              transition={{ duration: 0.15 }}
              className="absolute top-2 right-2 flex flex-col gap-2"
            >
              <motion.button
                whileTap={{ scale: 0.9 }}
                onClick={(e) => { e.stopPropagation(); handleAction('quero'); }}
                className={`p-2 rounded-full backdrop-blur-sm transition-colors ${
                  status === 'quero' 
                    ? 'bg-red-500 text-white' 
                    : 'bg-black/60 text-white hover:bg-black/80'
                }`}
              >
                <Heart size={18} fill={status === 'quero' ? 'currentColor' : 'none'} />
              </motion.button>
              
              <motion.button
                whileTap={{ scale: 0.9 }}
                onClick={(e) => { e.stopPropagation(); handleAction('tenho'); }}
                className={`p-2 rounded-full backdrop-blur-sm transition-colors ${
                  status === 'tenho' 
                    ? 'bg-blue-500 text-white' 
                    : 'bg-black/60 text-white hover:bg-black/80'
                }`}
              >
                <Library size={18} />
              </motion.button>
              
              <motion.button
                whileTap={{ scale: 0.9 }}
                onClick={(e) => { e.stopPropagation(); handleAction('li'); }}
                className={`p-2 rounded-full backdrop-blur-sm transition-colors ${
                  status === 'li' 
                    ? 'bg-green-500 text-white' 
                    : 'bg-black/60 text-white hover:bg-black/80'
                }`}
              >
                <BookOpen size={18} />
              </motion.button>
              
              <motion.button
                whileTap={{ scale: 0.9 }}
                onClick={(e) => { e.stopPropagation(); }}
                className="p-2 rounded-full bg-black/60 text-white backdrop-blur-sm hover:bg-black/80"
              >
                <Plus size={18} />
              </motion.button>
            </motion.div>
          )}
        </AnimatePresence>
      </div>
    </motion.div>
  );
}
```

#### Microinterações
- **Hover**: Scale 1.0 → 1.05 (0.2s, easeOut)
- **Ícones**: Fade in + slide up (0.15s)
- **Tap**: Scale 0.9 (feedback tátil)
- **Status Change**: Badge aparece com pop (scale 0.8 → 1.0)

│ │
│ │

#### Código (Tailwind + Framer Motion)
```tsx
'use client';

import { useState, useRef } from 'react';
import { motion, AnimatePresence } from 'framer-motion';
import { ChevronLeft, ChevronRight, Heart, Library, BookOpen } from 'lucide-react';

interface HeroCarouselProps {
  comics: Array<{
    id: string;
    titulo: string;
    url_capa: string;
    personagem_principal: string;
    preco_normal: number;
    preco_promocional: number | null;
  }>;
}

export function HeroCarousel({ comics }: HeroCarouselProps) {
  const [currentIndex, setCurrentIndex] = useState(0);
  const scrollRef = useRef<HTMLDivElement>(null);

  const scrollToIndex = (index: number) => {
    scrollRef.current?.scrollTo({
      left: index * scrollRef.current.clientWidth,
      behavior: 'smooth'
    });
    setCurrentIndex(index);
  };

  return (
    <div className="relative w-full h-[60vh] overflow-hidden">
      {/* Carrossel */}
      <div
        ref={scrollRef}
        className="flex w-full h-full overflow-x-auto snap-x snap-mandatory scrollbar-hide"
        onScroll={(e) => {
          const index = Math.round(e.currentTarget.scrollLeft / e.currentTarget.clientWidth);
          setCurrentIndex(index);
        }}
      >
        {comics.map((comic) => (
          <div
            key={comic.id}
            className="relative w-full h-full flex-shrink-0 snap-center"
          >
            {/* Capa */}
            <img
              src={comic.url_capa}
              alt={comic.titulo}
              className="w-full h-full object-cover"
            />
            
            {/* Overlay Gradiente */}
            <div className="absolute inset-0 bg-gradient-to-t from-black/90 via-black/40 to-transparent" />
            
            {/* Conteúdo */}
            <div className="absolute bottom-0 left-0 right-0 p-6 md:p-12">
              <motion.div
                initial={{ opacity: 0, y: 20 }}
                animate={{ opacity: 1, y: 0 }}
                transition={{ delay: 0.2 }}
                className="max-w-2xl"
              >
                {/* Badge */}
                <span className="inline-block px-3 py-1 bg-green-500 text-white text-sm font-semibold rounded-full mb-3">
                  Nova Edição
                </span>
                
                {/* Título */}
                <h1 className="text-white text-3xl md:text-5xl font-bold mb-2">
                  {comic.titulo}
                </h1>
                
                {/* Personagem */}
                <p className="text-gray-300 text-lg md:text-xl mb-4">
                  {comic.personagem_principal}
                </p>
                
                {/* Preço */}
                <div className="flex items-center gap-3 mb-6">
                  {comic.preco_promocional ? (
                    <>
                      <span className="text-green-400 text-2xl font-bold">
                        R$ {comic.preco_promocional.toFixed(2)}
                      </span>
                      <span className="text-gray-400 text-lg line-through">
                        R$ {comic.preco_normal.toFixed(2)}
                      </span>
                    </>
                  ) : (
                    <span className="text-white text-2xl font-bold">
                      R$ {comic.preco_normal.toFixed(2)}
                    </span>
                  )}
                </div>
                
                {/* Botões */}
                <div className="flex items-center gap-3">
                  <button className="px-6 py-3 bg-white text-black font-semibold rounded-md hover:bg-gray-200 transition-colors">
                    Ver Detalhes
                  </button>
                  
                  <button className="p-3 bg-black/60 text-white rounded-full backdrop-blur-sm hover:bg-black/80 transition-colors">
                    <Heart size={24} />
                  </button>
                  
                  <button className="p-3 bg-black/60 text-white rounded-full backdrop-blur-sm hover:bg-black/80 transition-colors">
                    <Library size={24} />
                  </button>
                  
                  <button className="p-3 bg-black/60 text-white rounded-full backdrop-blur-sm hover:bg-black/80 transition-colors">
                    <BookOpen size={24} />
                  </button>
                </div>
              </motion.div>
            </div>
          </div>
        ))}
      </div>
      
      {/* Setas de Navegação (Desktop) */}
      <button
        onClick={() => scrollToIndex(Math.max(0, currentIndex - 1))}
        className="absolute left-4 top-1/2 -translate-y-1/2 p-3 bg-black/60 text-white rounded-full backdrop-blur-sm hover:bg-black/80 transition-colors hidden md:block"
      >
        <ChevronLeft size={24} />
      </button>
      
      <button
        onClick={() => scrollToIndex(Math.min(comics.length - 1, currentIndex + 1))}
        className="absolute right-4 top-1/2 -translate-y-1/2 p-3 bg-black/60 text-white rounded-full backdrop-blur-sm hover:bg-black/80 transition-colors hidden md:block"
      >
        <ChevronRight size={24} />
      </button>
      
      {/* Dots de Navegação */}
      <div className="absolute bottom-4 left-1/2 -translate-x-1/2 flex items-center gap-2">
        {comics.map((_, index) => (
          <button
            key={index}
            onClick={() => scrollToIndex(index)}
            className={`w-3 h-3 rounded-full transition-colors ${
              index === currentIndex ? 'bg-white' : 'bg-white/40'
            }`}
          />
        ))}
      </div>
    </div>
  );
}
```

#### Microinterações
- **Auto-play**: Opcional (3s por slide)
- **Swipe**: Snap scroll nativo
- **Dots**: Hover → opacity 1.0
- **Conteúdo**: Fade in + slide up (delay 0.2s)

'use client';

import { useRef } from 'react';
import { motion } from 'framer-motion';

interface ContentRowProps {

  }>;
  onComicAction?: (comicId: string, action: 'quero' | 'tenho' | 'li') => void;
}

export function ContentRow({ title, comics, onComicAction }: ContentRowProps) {
  const scrollRef = useRef<HTMLDivElement>(null);

  return (
    <section className="py-8">
      {/* Título */}
      <div className="flex items-center justify-between px-6 mb-4">
        <h2 className="text-white text-xl font-semibold">{title}</h2>
        
        <button className="flex items-center gap-1 text-gray-400 hover:text-white transition-colors">

      {/* Grid Horizontal */}
      <div
        ref={scrollRef}
        className="flex gap-4 overflow-x-auto px-6 scrollbar-hide snap-x"
      >

'use client';

import { useState } from 'react';
import { motion } from 'framer-motion';
import { Home, Search, Library, Heart, User } from 'lucide-react';
import { usePathname, useRouter } from 'next/navigation';

export function BottomNav() {
  const pathname = usePathname();
  const router = useRouter();

  const tabs = [
    { id: 'home', label: 'Home', icon: Home, path: '/' },

              key={tab.id}

              className="flex flex-col items-center justify-center w-full h-full"

                }`}
              >
                {tab.label}
              </span>
            </button>
          );
        })}
      </div>
    </nav>
  );
}

- **Posição**: Header (top right)

- **Animação**: Rotate + fade

#### Código
```tsx
'use client';

import { useState, useEffect } from 'react';
import { motion } from 'framer-motion';
import { Sun, Moon } from 'lucide-react';

export function ThemeToggle() {
  const [isDark, setIsDark] = useState(true);

  useEffect(() => {
    document.documentElement.classList.toggle('dark', isDark);
  }, [isDark]);

  return (
    <button
      onClick={() => setIsDark(!isDark)}
      className="p-2 rounded-full bg-[#2B2B2B] text-white hover:bg- transition-colors"
    >
      <motion.div
        initial={false}
        animate={{ rotate: isDark ? 0 : 180 }}
        transition={{ duration: 0.3 }}
      >
        {isDark ? <Moon size={20} /> : <Sun size={20} />}
      </motion.div>
    </button>
  );
}
```
