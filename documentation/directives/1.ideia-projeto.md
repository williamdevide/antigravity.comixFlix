# ComixFlix — Arquitetura Técnica Completa

## Contexto
Você é um arquiteto de software sênior especializado em aplicações mobile-first e serverless. Estou construindo o **ComixFlix** — uma plataforma web (PWA) para colecionadores de quadrinhos físicos gerenciarem suas coleções, similar à Netflix mas para HQs.

O objetivo é criar um MVP em 4-6 semanas que seja escalável, performático e com excelente UX mobile.

---

## Requisitos Funcionais

### 1. Scrapers de Editoras (Brasil)

#### Editoras Alvo
- **Panini Brasil** (paninibooks.com.br)
- **Mythos Editora** (mythoseditora.com.br)
- **Pipoca & Nanquim** (pipocaenanquim.com.br)

#### Dados a Extrair (por edição)
- `titulo`: Nome completo da edição
- `editora`: Nome da editora
- `preco_normal`: Preço original (float)
- `preco_promocional`: Preço com desconto (float, nullable)
- `data_lancamento`: Mês/ano (string "MM/YYYY" ou Date)
- `url_capa`: URL da imagem da capa (alta resolução)
- `personagem_principal`: Personagem/título da série (string)
- `resumo_sinopse`: Descrição da edição (texto, 2-3 parágrafos)
- `isbn`: ISBN-13 (se disponível, string)
- `numero_edicao`: Número da edição (int, nullable)
- `serie`: Nome da série/revista mensal (string, nullable)
- `autores`: Roteirista, desenhista, colorista (array de strings)
- `paginas`: Número de páginas (int, nullable)
- `formato`: Físico, digital, luxo, etc. (string)
- `disponibilidade`: Em estoque, esgotado, pré-venda (string)
- `url_produto`: URL da página do produto na editora

#### Implementação Técnica
- **Runtime**: Firebase Functions (Node.js 18+)
- **Bibliotecas**:
  - `Puppeteer` ou `Playwright` para sites com JS dinâmico (Panini)
  - `Cheerio` ou `BeautifulSoup` para sites estáticos (Mythos, Pipoca & Nanquim)
- **Agendamento**: Cloud Scheduler (HTTP triggers)
  - Panini: Diário (muitos lançamentos)
  - Mythos: Semanal
  - Pipoca & Nanquim: Semanal
- **Tratamento de Erros**:
  - Retry com exponential backoff (3 tentativas)
  - Logging no Cloud Logging
  - Alertas no Cloud Monitoring se falhar > 3x consecutivas
- **Otimização**:
  - Cache de HTML por 6h (Redis ou Firestore)
  - Rate limiting (1 req/3s por domínio)
  - User-Agent rotation (evitar bloqueios)

  - Apple (Sign in with Apple)
  - Email/Senha (com verificação de email)
- **Recuperação de Senha**: Email com token temporário

#### Segurança (Firestore Rules)
```typescript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Users: apenas o próprio usuário pode ler/escrever
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
    
    // User Comics: apenas o próprio usuário
    match /user_comics/{docId} {
      allow read, write: if request.auth != null && 
        resource.data.user_id == request.auth.uid;
    }
    
    // Comics: leitura pública, escrita apenas via Functions
    match /comics/{comicId} {
      allow read: if true;
      allow write: if false; // apenas scrapers
    }
    
    // Wishlist: apenas o próprio usuário
    match /wishlist/{docId} {
      allow read, write: if request.auth != null && 
        resource.data.user_id == request.auth.uid;
    }
  }
}
```

#### Performance

- **CLS (Cumulative Layout Shift)**: < 0.1

- **WCAG 2.1 AA**: Contraste, foco visível, labels em ícones

- **Screen Readers**: ARIA labels, roles, live regions

#### Escalabilidade
- **Firestore**: Sharding por usuário se > 100k usuários
- **CDN**: Firebase Hosting + Cloud CDN para imagens
- **Rate Limiting**: Cloud Functions com limites por IP
- **Monitoring**: Cloud Logging, Cloud Monitoring, Error Reporting

### 4. Snippets de Código

#### A. Scraper da Panini (Puppeteer + Firebase Function)
```typescript
// functions/scrapers/panini.ts
import * as functions from 'firebase-functions';
import * as puppeteer from 'puppeteer';
import { getFirestore, Timestamp } from 'firebase-admin/firestore';
import { initializeApp } from 'firebase-admin/app';

initializeApp();
const db = getFirestore();

export const scrapePanini = functions
  .runWith({ timeoutSeconds: 540, memory: '2GB' })
  .https.onRequest(async (req, res) => {
    const browser = await puppeteer.launch({
      headless: 'new',
      args: ['--no-sandbox', '--disable-setuid-sandbox']
    });
    
    try {
      const page = await browser.newPage();
      await page.setUserAgent('Mozilla/5.0 (Windows NT 10.0; Win64; x64)...');
      
      // Navegar para página de lançamentos
      await page.goto('[https://paninibooks.com.br/quadrinhos](https://paninibooks.com.br/quadrinhos)', {
        waitUntil: 'networkidle2',
        timeout: 60000
      });
      
      // Extrair cards de produtos
      const comics = await page.evaluate(() => {
        const cards = document.querySelectorAll('.product-card');
        return Array.from(cards).map(card => {
          const titulo = card.querySelector('.product-title')?.textContent?.trim() || '';
          const precoNormal = parseFloat(
            card.querySelector('.price-regular')?.textContent?.replace('R$', '').trim() || '0'
          );
          const precoPromocional = parseFloat(
            card.querySelector('.price-sale')?.textContent?.replace('R$', '').trim() || '0'
          ) || null;
          const urlCapa = card.querySelector('.product-image img')?.getAttribute('src') || '';
          const urlProduto = card.querySelector('a')?.getAttribute('href') || '';
          const personagem = card.querySelector('.product-series')?.textContent?.trim() || '';
          
          return {
            titulo,
            editora: 'Panini',
            preco_normal: precoNormal,
            preco_promocional: precoPromocional,
            url_capa: urlCapa,
            url_produto: urlProduto,
            personagem_principal: personagem,
            source: 'panini',
            last_scraped_at: Timestamp.now()
          };
        });
      });
      
      // Upsert no Firestore
      const batch = db.batch();
      for (const comic of comics) {
        const existing = await db.collection('comics')
          .where('url_produto', '==', comic.url_produto)
          .limit(1)
          .get();
        
        if (existing.empty) {
          const ref = db.collection('comics').doc();
          batch.set(ref, {
            ...comic,
            created_at: Timestamp.now(),
            updated_at: Timestamp.now()
          });
        } else {
          const ref = existing.docs.ref;
          batch.update(ref, {
            ...comic,
            updated_at: Timestamp.now()
          });
        }
      }
      
      await batch.commit();
      res.status(200).send({ success: true, count: comics.length });
    } catch (error) {
      console.error('Erro no scraper Panini:', error);
      res.status(500).send({ success: false, error: error.message });
    } finally {
      await browser.close();
    }
  });
```

#### D. Hook React Query para Buscar Edições Filtradas
```typescript
// lib/hooks/useComics.ts
import { useQuery } from '@tanstack/react-query';
import { getFirestore, collection, query, where, orderBy, limit, getDocs } from 'firebase/firestore';

const db = getFirestore();

interface FilterOptions {
  editora?: string[];
  personagem?: string[];
  serie?: string;
  precoMin?: number;
  precoMax?: number;
  dataInicio?: string;
  dataFim?: string;
  disponibilidade?: string;
  sortBy?: 'data_lancamento' | 'preco_normal' | 'titulo';
  sortOrder?: 'asc' | 'desc';
  page?: number;
  pageSize?: number;
}

export function useComics(filters: FilterOptions = {}) {
  const {
    editora,
    personagem,
    serie,
    precoMin,
    precoMax,
    dataInicio,
    dataFim,
    disponibilidade,
    sortBy = 'data_lancamento',
    sortOrder = 'desc',
    page = 1,
    pageSize = 20
  } = filters;

  return useQuery({
    queryKey: ['comics', filters],
    queryFn: async () => {
      let q = query(collection(db, 'comics'));
      
      // Filtros
      if (editora?.length) {
        q = query(q, where('editora', 'in', editora));
      }
      
      if (personagem?.length) {
        q = query(q, where('personagem_principal', 'in', personagem));
      }
      
      if (serie) {
        q = query(q, where('serie', '==', serie));
      }
      
      if (precoMin !== undefined) {
        q = query(q, where('preco_normal', '>=', precoMin));
      }
      
      if (precoMax !== undefined) {
        q = query(q, where('preco_normal', '<=', precoMax));
      }
      
      if (disponibilidade) {
        q = query(q, where('disponibilidade', '==', disponibilidade));
      }
      
      // Ordenação
      q = query(q, orderBy(sortBy, sortOrder));
      
      // Paginação
      q = query(q, limit(pageSize));
      
      const snapshot = await getDocs(q);
      return snapshot.docs.map(doc => ({ id: doc.id, ...doc.data() }));
    },
    staleTime: 5 * 60 * 1000, // 5 minutos
    gcTime: 30 * 60 * 1000 // 30 minutos
  });
}
```
