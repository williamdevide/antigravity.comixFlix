# SOP-003: Design System, Tokens e Integração Google Stitch

## 1. Identificação
- **Código:** SOP-003
- **Título:** Governança do Design System e Fidelidade ao Protótipo Google Stitch
- **Módulo:** UI / UX / Design System
- **Responsável:** Frontend Specialist & UI/UX Designer
- **Versão:** 1.0.0
- **Data:** 2026-09-20

## 2. Objetivo
Assegurar paridade visual absoluta com a especificação `5.design.md` e os ativos gerados no Google Stitch (Projeto ID: `10544063761972209689`), mantendo a estética imersiva "streaming de quadrinhos".

## 3. Tokens de Cor Principais (Dark Mode Padrão)
- **Canvas Base:** `#141414` (Fundo primário)
- **Surface:** `#1F1F1F` (Cards e superfícies intermediárias)
- **Elevated:** `#2B2B2B` (Modais, menus e tooltips)
- **Brand Primary:** `#E50914` (Hover: `#F40612`, Active: `#B20710`)
- **Status Collection ("Tenho"):** `#4DA3FF` (Azul colecionador)
- **Status Wishlist ("Quero"):** `#E50914` (Vermelho coração)
- **Status Success ("Li"):** `#46D369` (Verde leitura concluída)
- **Promoção / Destaque:** `#FFB400` (Amarelo dourado de oferta)
- **Bordas Sutis:** `#404040`

## 4. Tipografia e Escalas
- Fonte primária: `Inter`, sans-serif.
- Proporção padrão de capas: `aspect-[2/3]`
- Área mínima de toque mobile: `44px x 44px`
- Logotipo oficial: Vetor SVG com polígono dinâmico estilo balão/painel e wordmark `COMIXFLIX`.
